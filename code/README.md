Dungeon — Легендарная команда

Описание проекта



Игра Dungeon — это пошаговая битва героев с боссом.



Добавленные классы

Hero — базовый класс героя.

Archer — лучник с критическими ударами.

Paladin — паладин с мощной атакой.

Boss — Темный дракон.

Inventory — инвентарь.

Новые предметы

Sword — легендарный меч с бонусом атаки +15.

HealthPotion — лечебное зелье, восстанавливающее 50 HP.

Дополнительные возможности

Критические удары с вероятностью 25%.

Особые способности героев.

Битва с боссом.

Как запустить игру

Установить Python 3.

Открыть терминал в папке проекта.

Выполнить команду:

bash

python main.py
